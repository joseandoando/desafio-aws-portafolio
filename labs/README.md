# Cloud Engineering Labs — Jose Calfullan

Hands-on projects focused on AWS, DevOps, SRE, automation and production operations.

## Featured projects

### 1. SRE / DevOps Observability Lab

[`sre-observability-lab/`](sre-observability-lab/)

Production-oriented reliability lab featuring:

- AWS ECS Fargate + Application Load Balancer
- Terraform Infrastructure as Code
- CloudWatch Logs, Container Insights and alarms
- Docker / Docker Compose
- Prometheus + Grafana
- Health/readiness checks and application metrics
- SLI/SLO definitions and error-budget concepts
- P0/P1 incident response runbook
- Bash smoke tests
- GitHub Actions CI

**Best for:** SRE, DevOps Engineer, Cloud Engineer and Platform Engineer interviews.

### 2. AWS Data Engineering Lab

[`aws-data-pipeline/`](aws-data-pipeline/)

AWS-oriented data pipeline featuring:

- Amazon S3
- AWS Glue Data Catalog / Glue Job design
- PySpark
- Parquet
- Amazon Athena
- Python + Boto3
- Terraform
- Docker-based local AWS-compatible integration testing
- GitHub Actions

**Best for:** AWS Cloud, Data Engineering and Backend/Cloud interviews.

## Engineering principles demonstrated

- Infrastructure as Code instead of manual provisioning
- Automated validation in CI
- Monitoring based on actionable signals
- Documentation and repeatable runbooks
- Local reproducibility before cloud deployment
- Security-aware IAM and network design
- Explicit distinction between tested local behavior and real AWS deployment
